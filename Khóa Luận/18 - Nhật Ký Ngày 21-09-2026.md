## 1. Bối Cảnh & Động Lực Nâng Cấp Mô Hình 🚀

### Vấn đề Quota & Tình trạng mô hình cũ
- **Hạn ngạch siết chặt:** Trên Google AI Studio (Free Tier), Google đã điều chỉnh hạn ngạch các model Flash lớn (`Gemini 2.5 Flash Lite`, `Gemini 3 Flash`, `Gemini 3.5 Flash`, `Gemini 3.7 Flash`) xuống chỉ còn **20 RPD (Requests Per Day)**. Khi chạy kiểm thử đa lượt (multi-turn) trong n8n, hạn mức này bị cạn kiệt rất nhanh (HTTP 429).
- **Lỗi quá tải 503:** Model cũ `models/gemini-2.5-flash` thường xuyên gặp lỗi `503 UNAVAILABLE: This model is currently experiencing high demand`.
- **Ưu thế vượt trội của Gemini 3.1 Flash Lite:**
  - **500 RPD (Requests Per Day)** — gấp **25 lần** so với hạn mức 20 RPD.
  - **15 RPM** (Requests Per Minute) & **250.000 TPM** (Tokens Per Minute).
  - Hỗ trợ đầy đủ **Tool Calling (Function Calling)** và cơ chế suy luận ngầm (*Thinking*).

## 2. Các Thay Đổi Kỹ Thuật Đã Triển Khai 🛠️

### 2.1. Cập nhật n8n Workflows
1. **Đồng bộ Model:** Cập nhật node `Gemini Flash` trong cả 3 sub-agents ([02-hr-qa-agent.json](file:///c:/Users/Admin/Documents/admin/khoa-luan/n8n-workflows/02-hr-qa-agent.json), [03-training-agent.json](file:///c:/Users/Admin/Documents/admin/khoa-luan/n8n-workflows/03-training-agent.json), [04-zalo-cskh.json](file:///c:/Users/Admin/Documents/admin/khoa-luan/n8n-workflows/04-zalo-cskh.json)) sang `models/gemini-3.1-flash-lite`.
2. **Khắc phục lỗi schema tool RAG (WF02):**
   - Trong node `SearchPolicyKnowledge`, tham số `topK` trước đây đặt `valueProvider: "modelRequired"`. Khi model chỉ gửi `{ query }` mà quên `topK`, LangChain văng lỗi `ToolInputParsingException: Required at topK`.
   - **Giải pháp:** Đổi `topK` sang `valueProvider: "fieldValue"`, cố định giá trị `3`. Model chỉ cần tập trung sinh query tìm kiếm, không bao giờ bị lỗi schema.
3. **Sửa lỗi Race Condition & Authentication (WF03):**
   - Node `Load Scenario` trước đây nối song song sang cả `Action Switch` lẫn `Get/Create Session`, khiến `Training Agent` chạy khi chưa có session ID (văng lỗi `No session ID found` tại `Postgres Chat Memory`). Đã chỉnh lại luồng tuần tự: `Load Scenario` → `Get/Create Session` → `Restore Item` → `Action Switch`.
   - Bổ sung cấu hình `genericCredentialType` ("NestJS API Key") cho các node `Save User Message`, `Save Quiz Assistant Message`, `Save Grade Assistant Message`.
4. **Triển khai live lên n8n:**
   - Sử dụng script `scripts/update-gemini-model.cjs` gọi REST API của n8n, patch trực tiếp và kích hoạt lại toàn bộ workflow đang chạy.

## 3. Kết Quả Kiểm Thử Toàn Diện 4 Workflows (100% PASS) ✅

### 🎯 WF01 — Router Agent

- **Kết quả:** Phân loại đúng intent `OTHER`, trả về static message hướng dẫn ngay lập tức.
- **Thời gian phản hồi:** **49ms** (0 LLM call, tiết kiệm 100% token).

### 🎯 WF02 — HR Q&A Agent (Tool Calling & RAG)
- **Kịch bản 1 (Tra cứu bảng lương):**
  - *Query:* `"Lương tháng 8/2026 của tôi là bao nhiêu?"` (EMP003).
  - *Kết quả:* Gemini 3.1 Flash Lite gọi tool `GetPayrollContext`, trích xuất chính xác lương thực lãnh **29.885.544 VNĐ**, kèm chi tiết khấu trừ và thuế TNCN (**7.1s**).
- **Kịch bản 2 (RAG Chính sách nhân sự):**
  - *Query:* `"chinh sach nghi phep la gi"`.
  - *Kết quả:* Gọi tool `SearchPolicyKnowledge`, tìm kiếm tương đồng vector qua `gemini-embedding-001`, trích dẫn chính xác 12 ngày phép theo văn bản `QUY CHE LD 2024 - MUC 4` (**7.6s**).

### 🎯 WF03 — Training Agent (Role-play & Quiz)
- **Kịch bản 1 (Role-play tình huống):**
  - *Query:* `"toi muon luyen tap ky nang giao tiep"` (`scenarioType: customer_complaint`).
  - *Kết quả:* AI khởi tạo kịch bản xử lý khiếu nại khách hàng, đóng vai tự nhiên, lưu lịch sử vào PostgreSQL Chat Memory (**6.9s**).
- **Kịch bản 2 (Tự động sinh bài Quiz đào tạo):**
  - *Query:* `"lam bai test"` (`action: generate_quiz`).
  - *Kết quả:* Quiz Gen Agent sinh đầy đủ 5 câu trắc nghiệm MCQ (có các lựa chọn A/B/C/D, đáp án đúng và giải thích) + 2 câu tự luận chuyên sâu theo kịch bản khiếu nại (**8.1s**).
- **Kịch bản 3 (Chấm điểm qua API NestJS):**
  - *Gửi bài làm tới:* `POST /api/v1/training/submit`.
  - *Kết quả:* Hệ thống chấm điểm, tạo `TrainingSession` và `TrainingAttempt` lưu vào PostgreSQL (**4.1s**).

### 🎯 WF04 — CSKH Agent (Human-in-the-Loop & Escalation)
- **Kịch bản 1 (Tư vấn gói dịch vụ qua Router):**
  - *Query:* `"Tôi muốn hỏi về sản phẩm dịch vụ TechHRM"`.
  - *Kết quả:* AI tư vấn đầy đủ 3 gói Basic (500k), Pro (1tr2), Enterprise và chính sách dùng thử 30 ngày.
- **Kịch bản 2 (Tương tác qua Webhook Zalo/Slack):**

  - *Kết quả:* Bot phản hồi chính xác, lưu message vào DB với metadata `model: 'gemini-3.1-flash-lite'`.
- **Kịch bản 3 (Phát hiện khiếu nại nghiêm trọng & Escalation):**
  - *Query:* `"Dịch vụ của công ty quá tệ, dữ liệu bị mất sạch, tôi khiếu nại yêu cầu bồi thường thiệt hại và gặp lãnh đạo ngay!"`.
  - *Kết quả:*
    1. AI nhận diện vượt thẩm quyền, chèn tag escalation.
    2. Gọi endpoint `/api/v1/n8n/escalate`.
    3. Tự động chuyển `session.isActive = false` (bot im lặng để người tiếp quản).
    4. Ghi nhận lý do: `"Khách hàng khiếu nại về mất dữ liệu, yêu cầu bồi thường và gặp lãnh đạo"`.
    5. Tạo Notification loại `SYSTEM` gửi đến Admin Portal.
