### Bug đã fix: NaN crash khi thiếu month/year params

**Root cause:** `Number(undefined) = NaN` → `new Date(NaN, NaN-1, 1)` = Invalid Date → Prisma crash 500.

**Cách fix:** Thêm `|| now.getMonth() + 1` / `|| now.getFullYear()` fallback trong controller:

## 3. Real-time AI Panel via WebSocket (Push-only)

### Vấn đề với polling 1s
- REST polling 1s → N×60 req/phút × số admin đang online = tải DB không cần thiết
- Dữ liệu AI activity chỉ thay đổi khi n8n gọi `saveMessage()` — tức là rất thưa

### Giải pháp: WebSocket push-only
Server chỉ emit khi thực sự có AI message mới vào DB → **0 request** khi hệ thống idle.

#### Thiết kế
- **Transport:** socket.io (đã có `NotificationsGateway` trên namespace `/notifications`)
- **Trigger:** `AiContextService.saveMessage()` hook sau khi persist DB
- **Broadcast target:** Room `'admin'` — chỉ ADMIN/HR_MANAGER/HR_ADMIN
- **Payload:** `{ wf, label, total, avgLatencyMs, lastActiveAt }` — client update row in-place
- **Badge:** Dot xanh pulse = connected, xám = disconnected

#### Files thay đổi

**Backend:**
```
notifications.gateway.ts   → thêm join-admin handler + emitAiActivity()
ai-context.module.ts       → import NotificationsModule
ai-context.service.ts      → inject gateway, hook saveMessage() emit WS sau DB
notifications.module.ts    → xóa AiContextModule (tránh circular dep)
```

**Frontend:**
```
lib/hooks/useAiSocket.ts   → [NEW] WebSocket hook (connect, join-admin, listen ai:activity)
dashboard-view.tsx         → dùng hook, update row in-place, badge live state
```

#### So sánh hiệu năng
| Phương pháp | Request/phút (1 admin) | DB query/phút |
|------------|----------------------|---------------|
| REST polling 1s | 60 | 60 |
| WebSocket push | **0** (chỉ khi có data) | **0** |

## 5. Lưu Ý Kỹ Thuật

### Tránh circular dependency
`AiContextModule` import `NotificationsModule` (để inject gateway).  
`NotificationsModule` KHÔNG import `AiContextModule` nữa (đã xóa để tránh vòng tròn).

### @Optional() decorator
`NotificationsGateway` được inject với `@Optional()` vào `AiContextService` — đảm bảo service không crash nếu gateway chưa khởi tạo kịp.

### useAiSocket hook pattern
- Dùng `useRef` cho callback `onActivity` để tránh re-connect khi component re-render
- Chỉ connect khi `userId != null && isAdmin == true`
- Reconnect tự động với delay 2s → max 10s
